# 🔎 Найди всё!

Мобильная HTML-игра для маленьких детей.

## Как запустить
Откройте `index.html` в браузере.

## Как опубликовать на GitHub Pages
1. Создайте новый публичный репозиторий на GitHub.
2. Загрузите `index.html`.
3. Settings → Pages → Deploy from a branch → `main` → `/root`.
4. Сохраните настройки — GitHub выдаст адрес игры.

Игра полностью работает на клиенте и не требует сервера.
