# Где спрятался малыш?

Мобильная HTML-игра по концепции скрытых предметов.

## Запуск
Откройте `index.html`.

## GitHub Pages
Загрузите `index.html` в публичный репозиторий → Settings → Pages → Deploy from branch → `main` / root.

Игра работает полностью в браузере, без сервера и сторонних библиотек.
